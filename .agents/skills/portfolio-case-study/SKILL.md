# Vaka Çalışması Üretici

Sayfa şu bölümleri sırayla içermeli:
1. Başlık + tek cümlelik özet
2. Problem
3. Rolüm
4. Mimari (şema/diyagram)
5. Teknolojiler (etiket listesi)
6. En zor teknik sorun
7. Sonuç (ölçülebilir değer varsa yaz, yoksa uydurma)
8. Bağlantılar

## Kurallar
- Notlarda olmayan bilgiyi ekleme; eksikleri `[BİLGİ GEREKLİ]` ile işaretle.
- Renkleri sadece CSS değişkenleriyle kullan (`AGENTS.md`'deki palet).
- Her görsele alt metin yaz; WebP kullan.
- Mevcut proje kartı bileşenini yeniden kullan, yenisini üretme.
