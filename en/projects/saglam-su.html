Sağlam Su

A multi-brand water distribution catalog with automated WhatsApp order drafts, custom brand monogram, and a native Android product management app.

Role
Solo developer
Type
Client project
Platform
Web + Android admin
Year
2025

Problem

A local multi-brand water distributor needed a clean storefront showing live product availability and prices, generating pre-filled WhatsApp order messages, and letting the owner add or update items from their phone.

My Role

I delivered every component: brand logo design, a 5-page website (index, urunler, urun-detay, hakkimizda, iletisim), sitemap.xml / robots.txt SEO setup, PowerShell image resizing scripts, and a native Android admin app synced with Firebase Realtime Database.

Architecture

1 · Storefront catalog 5-page static web products-loader.js and urunler-loader.js fetch live Firebase inventory and generate one-tap WhatsApp orders.
2 · Database Firebase Realtime DB Public read access with authenticated admin-only write permissions enforced via database.rules.json.
3 · Management Native Android panel Lets the business owner add products, edit pricing, and remove items directly from mobile.

Technologies

HTML / CSS / JS Firebase Realtime DB Firebase Hosting Android WhatsApp API SEO (Sitemap)

Outcome

Delivered the website, brand logo, and Android management app to the client. Building a native Android panel here directly informed my decision to switch to a cross-platform PWA admin panel in my next client project, Dolunay Cafe.
