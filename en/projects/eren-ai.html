Eren AI

A personal Android AI assistant that opens apps, calls contacts, controls music and device settings via voice, handles open-ended prompts with Google Bard, and syncs user sessions and data via Firebase.

Role
Solo developer
Platform
Android (minSdk 24 – 35)
Scope
Google Bard · Firebase · 22 Kotlin files
Year
2025

Problem

I wanted to unify everyday Android actions — launching apps, dialing contacts, controlling media and brightness/volume, translating across 50+ languages, scanning barcodes, and answering open-ended questions — inside a single voice chat experience with secure cloud session and history sync.

My Role

I built the app solo using Kotlin and Android XML (ViewBinding). I implemented the Google TTS/STT voice loop, a hybrid natural-language layer combining key-value intent matching (IntentDetector) with Google Bard, secure authentication and real-time sync via Firebase Auth & Realtime Database, 50+ language translation via MyMemory API, and a CameraX + ML Kit barcode scanner with link routing.

Architecture

1 · Voice & NLP Google STT + Bard + Intent Matches deterministic device commands via key-value IntentDetector first, routing open-ended queries with ContextManager context to Google Bard.
2 · Device & tools System, camera & translation AppLauncher, ContactManager, media/system controls, CameraX + ML Kit autofocus/flash barcode scanner, link router, and 50+ language MyMemory translation.
3 · Cloud & speech Firebase & Google TTS Firebase Auth for secure sessions, Firebase Realtime Database for real-time chat/preference sync, and TTSManager for spoken responses.

Technologies

Kotlin Android Studio & XML Google Bard (NLP) Firebase Auth Firebase Realtime Database Google TTS / STT CameraX & ML Kit Barcode MyMemory API

Hardest technical challenge

The key challenge was separating deterministic device commands (opening apps, calling contacts, toggling music or settings) that must execute instantly from open-ended AI prompts without introducing latency or misrouting.

I solved this with a two-stage routing pipeline: a lightweight key-value IntentDetector resolves local device commands in milliseconds and dispatches them directly to system managers, while unmatched natural-language prompts flow with conversation context into the Google Bard layer, returning spoken output via TTSManager and persisting state to Firebase Realtime Database.

Outcome

This project gave me deep hands-on experience with Android runtime permissions, CameraX lifecycles, ML Kit vision, hybrid NLP routing, and Firebase Auth/Realtime Database integration — paving the way for Watchly's Jetpack Compose and Cloud Functions architecture.
