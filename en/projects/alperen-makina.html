Alperen Makina

A bilingual Turkish/English corporate website and industrial machine catalog built for Alperen Makina, manufacturing yarn winding machinery since 1970.

Role
Solo developer
Type
Client project
Live URL
alperenmakinasanayi.com
Year
2025

Problem

Industrial manufacturers need to present machinery clearly with photos and videos to both domestic and export buyers, and provide one-tap quote requests via WhatsApp, phone, or email.

My Role

I designed and built the 5-page static website (home, about, machines, machine detail, and contact) from scratch with Vite 8, implemented client-side TR/EN switching via translations.js, and deployed it on Firebase Hosting.

Architecture

1 · Multi-page Vite 8 5 static HTML pages index, hakkimizda, makinelerimiz, makine-detay, and iletisim bundled cleanly.
2 · Localization translations.js (TR / EN) Lightweight client-side dictionary enabling instant Turkish/English switching without page reloads.
3 · Hosting & contact Firebase Hosting & Maps Global CDN delivery, Google Maps factory location, and direct WhatsApp/phone quote links.

Technologies

Vite 8 HTML / CSS / JS Firebase Hosting TR / EN i18n Google Maps API

Outcome

Actively live at alperenmakinasanayi.com. Prospective customers browse machine photos and videos and reach the factory directly via WhatsApp or phone.
