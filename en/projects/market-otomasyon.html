Market Automation System

A JavaFX desktop application with admin and accounting roles, custom linked-list inventory tracking, and automated expiration-date monitoring.

Type
University project
Platform
Desktop (Java 21)
UI
JavaFX 21 + 3 FXML
Year
2025

Problem

As a practical Data Structures course project, I needed to model a realistic grocery inventory workflow without relying on built-in collections: role-based authentication, barcode/category search, highlighting near-expiry or expired goods, and an accounting view.

My Role

I built the JavaFX / FXML views (login.fxml, market_view.fxml, Muhasebe-view.fxml), three controllers (LoginController, MarketController, MuhasebeController), a from-scratch BagliListe linked list, SKTDurum expiration checks, and single-JAR packaging via Maven Shade Plugin.

Architecture

1 · UI (FXML) 3 role-based screens LoginController verifies credentials and routes users to MarketController (inventory) or MuhasebeController (accounting).
2 · Data structures BagliListe & UrunArama Custom linked list for CRUD operations, paired with KategoriYonetimi, Sorgu, and SKTDurum expiry validation.
3 · Persistence & build DosyaIslemleri & Shade JAR File-based persistence layer and Maven Shade Plugin bundling all dependencies into a single runnable JAR.

Technologies

Java 21 JavaFX 21 FXML Maven Maven Shade Plugin LinkedList

Outcome

Delivered a cleanly separated MVC desktop application that resolves JavaFX manifest/signature conflicts with Maven Shade filters and ships as a single executable JAR.
